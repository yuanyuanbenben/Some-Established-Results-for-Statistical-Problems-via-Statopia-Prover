# Statistics dataset metadata

[benchmark.yaml](benchmark.yaml) preserves historical MSC62 metadata. [track_b_cases.txt](track_b_cases.txt) records the original candidate paths. These historical lists are not standalone build inputs.

The selected 83 results are enumerated in [the catalogue](../../CATALOG.md); complete theorem signatures are in [SIGNATURES.md](../SIGNATURES.md). Each selected case retains its own question, input Lean and proof. Use `make verify` at the project root to compile the reproduction copies.
